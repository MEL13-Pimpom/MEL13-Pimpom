# Recycling Pickup Scheduler

## Project Description

The Recycling Pickup Scheduler is a web-based system that allows residents to schedule recycling pickup requests. It also provides functionalities for administrators to manage requests and for collectors to complete assigned tasks.

## Objectives

* Simplify the recycling request process
* Improve waste collection management
* Provide a structured system for all user roles
* Encourage environmentally friendly practices

## User Roles

### Resident

* Submit pickup requests
* View request status
* Cancel or reschedule requests
* Receive notifications

### Admin

* Manage user accounts
* Approve or reject requests
* Assign tasks to collectors
* Monitor system activity

### Collector

* View assigned tasks
* Update pickup status
* Manage schedule

## Key Features

* User authentication
* Pickup request submission
* Request approval system
* Task assignment
* Notification system
* Role-based dashboards
